# 社会テスト対策 通常＋変態モード（年号問題切替版）

- 一度に表示されるのは1問だけ
- 通常モード／変態モード／ミックス
- 四択・記述
- 単元・形式・出題数フィルター
- 「年号問題を含める」チェックボックスを追加
- 初期状態では年号ドリルを除外
- 広島・長崎への原爆投下など、特に重要な日付問題は除外対象外
- 間違えた問題だけ再挑戦可能
- 完全静的。`index.html`だけで動作

## 年号問題の判定
今回、年号そのものを答えさせる問題や、年号だけを手掛かりに出来事を特定する問題を `yearOnly` として分類しています。

分類された年号問題：100問
- 通常：99問
- 変態：1問

チェックを外している間は、これらを出題候補から外します。
